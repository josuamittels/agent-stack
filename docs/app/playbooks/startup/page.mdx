# Startup journey

Use the Startup Journey to see the intended sequence from a startup idea through market research, strategy, a design system, and a voice profile. This resource is an outline, not an executable process: it does not define detailed actions, selection criteria, inputs, handoffs, or completion conditions for the stages.

## Intended sequence

1. Market research
2. Strategy
3. Design system
4. Voice profile

The final stage connects to [Compose Voice Profile](/capabilities/skills/compose-voice-profile), an available experimental skill. The outline does not specify executable capabilities for the earlier stages.
