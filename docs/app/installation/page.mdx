# Installation & updates

Install Agent Stack skills from GitHub for Codex or Claude Code. The stack is experimental; individual skills have their own lifecycle status.

## Install skills

Run the command for your host from the project where you want to use the skills:

```sh
# Codex
npx skills add josuamittels/agent-stack --skill '*' -a codex

# Claude Code
npx skills add josuamittels/agent-stack --skill '*' -a claude-code
```

Replace `'*'` with one or more skill names to select a smaller set. Add `-g` for user-wide availability. Each skill carries its required helper snapshots and guidelines; separately installed helpers remain independently invocable. Installation does not modify your project's agent instructions.

Find capability groups and their quick starts in the [repository README](https://github.com/josuamittels/agent-stack/blob/main/README.md), or explore the [capabilities](/capabilities) for detailed workflows.

## Local preview

To try source changes, run `npm ci --ignore-scripts` followed by `npm run build:preview` from a clone of the repository. Replace `/absolute/path/to/agent-stack` below with your clone's location and run the command from your target project:

```sh
# Codex
npx skills add /absolute/path/to/agent-stack/dist/preview/skills --skill '*' -a codex

# Claude Code
npx skills add /absolute/path/to/agent-stack/dist/preview/skills --skill '*' -a claude-code
```

Preview builds include experimental candidates without changing their lifecycle status.

## Updates

Use `npx skills check`, `npx skills update translate`, or `npx skills update` with the appropriate installation scope. Remove a skill with `npx skills remove translate`. To obtain newly added skills, rerun the full-set installation command. Use a release-tag GitHub tree URL to pin or roll back to an existing version.

## Plugins and configuration

Generated distributions contain full and individual plugins for Claude Code and supported OpenAI local clients. ChatGPT workspace/plugin installation is separate from installing a Codex skill through a terminal command. Client support and workspace policy determine availability.

Save configuration outside packages using `AGENT_STACK_CONFIG_DIR` and writable evaluation history using `AGENT_STACK_STATE_DIR`. Updates replace packaged files without replacing these external directories.

See the [complete installation and distribution guide](https://github.com/josuamittels/agent-stack/blob/main/docs/distribution.md) and [generated candidate commands](https://github.com/josuamittels/agent-stack/blob/main/docs/installation.generated.md) for host paths, dependency lists, native plugin setup, and maintenance.
