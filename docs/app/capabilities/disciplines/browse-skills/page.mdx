# Browse Skills

> **Discipline** · **experimental** · **v1.1.0** · updated 2026-10-28

## Purpose

Use Browse Skills to find and inspect public skills that can inform a defined workflow or capability.

## Workflow

1. **Set the research brief.** Name the capability, failure mechanism, research questions, search terms, and destination for findings.
2. **Find relevant candidates.** Search the supported catalog and follow useful listings to their original repositories.
3. **Inspect and compare sources.** Read the actual instructions and needed resources, distinguish observed guidance from performance claims, and record what to adopt or reject.
4. **Return the findings.** Summarize source coverage, useful approaches, limitations, and open gaps for the owning task.

## Inputs

Use the intended outcome, candidate skill name or guideline subject, current stage, relevant context and already selected references, constraints, specific research questions, useful search terms, supplied sources or prior findings, and the caller's research-record path. For a repair, include the reported failure mechanism. Use only public, non-sensitive concepts in external searches.

## Routing and related capabilities

The [Skill Issue router](/capabilities/router/skill-issue) can select this discipline for a focused task. Skills also hand off to disciplines when their workflows need a reusable method; follow the links in each skill’s Workflow section.
