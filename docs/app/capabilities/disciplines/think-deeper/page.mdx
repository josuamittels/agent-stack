# Think Deeper

> **Discipline** · **experimental** · **v0.2.0** · updated 2026-10-28

## Purpose

Use Think Deeper to strengthen the evidence, methods, tools, and checks for a substantive task without changing its goal.

## Workflow

1. **Fix the goal and scope.** State the requested outcome and constraints so the work stays bounded.
2. **Find the primary material.** Inspect the closest available evidence and identify what inaccessible material would limit the result.
3. **Choose a method and outside check.** Select methods that can improve the answer and define a practical check that could disagree with it.
4. **Do the work and report evidence.** Carry out the authorized task and distinguish observed results, assumptions, and remaining limits.

## Inputs

Use your goal, requested deliverable, constraints, known assumptions, available source material, tools, access, and any acceptance criteria. Identify which details are established and which are assumptions. Do not assume that raw data, software installation, external services, or additional permissions are available.

## Result

For a prompt rewrite, return the unchanged goal, the chosen source material and methods, the outside check and pass condition, any missing access, and a copyable prompt. For task execution, report the work completed, evidence and check results, and remaining limits. Keep the explanation proportionate; do not make the response longer merely to display every step.
