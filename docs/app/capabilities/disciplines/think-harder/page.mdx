# Think Harder

> **Discipline** · **stable** · **v1.0.0** · updated 2026-10-31

## Purpose

Use Think Harder to resolve ambiguity from the request, repository context, and available evidence before asking the user.

## Workflow

1. **Name the uncertainty.** Identify which unresolved choice could materially change the outcome.
2. **Inspect the available context.** Review relevant instructions, evidence, precedents, and reasonable defaults.
3. **Resolve or ask.** State the assumption when context settles the choice; otherwise route a focused question through [Ask User Question](/capabilities/disciplines/ask-user-question).

## Inputs

Use the caller's identity and current stage, original user outcome and exact framing, relevant chat history and prior answers, unresolved constraints, available artifacts, explicit permissions, and the guidelines already selected or triggered by the caller. Identify guideline paths and applicable sections when available. Reconstruct missing handoff context from accessible task materials before asking for it.
