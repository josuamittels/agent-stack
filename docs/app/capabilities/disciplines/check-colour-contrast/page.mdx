# Check Colour Contrast

> **Discipline** · **stable** · **v1.1.0** · updated 2026-10-28

## Purpose

Use Check Colour Contrast to calculate the contrast ratio for a supplied foreground and background colour pair.

## Workflow

1. **Provide the colour pair.** Supply both colour values and the relevant text or interface context.
2. **Compare the ratio with the target.** Calculate the ratio and compare it with the requested WCAG threshold; report the result and its scope.

## Inputs

Provide opaque foreground and background colors, each with its format (`hex`, `rgb`, or `hsl`) and value.

## Result

Return the calculated ratio and pass/fail results for normal text, large text, and non-text UI/graphics.
