# Pre Mortem

> **Discipline** · **experimental** · **v0.2.0** · updated 2026-10-28

## Purpose

Use Pre-Mortem to find plausible failure paths in a concrete plan while the owner can still change it.

## Workflow

1. **Set the plan and horizon.** Name the intended outcome, success condition, adjustable actions, and point at which failure will be judged.
2. **Assume the plan failed.** Use the chosen horizon and generate distinct causal paths anchored in the actual plan.
3. **Turn causes into changes.** Identify evidence or actions that could reduce the strongest failure paths, and leave the decision with the plan owner.

## Inputs

Use the plan, its owner, intended outcome, success condition, relevant time horizon, constraints, available records, and prior decisions. Recover details from the conversation and accessible files before asking for them. Distinguish known facts from assumptions.
