# Convert Colour

> **Discipline** · **stable** · **v1.1.0** · updated 2026-10-28

## Purpose

Use Convert Colour to convert a supplied colour value between explicitly requested colour formats.

## Workflow

1. **Provide the value and formats.** Name the colour value, its source space, and the target format; include alpha or profile details when relevant.
2. **Convert and report.** Return the converted value with any precision or gamut limitation that affects interpretation.

## Inputs

Provide the input format, color value, and output format.

## Result

Return the converted value printed by the script.
