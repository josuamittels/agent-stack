# Answer Interview

> **Skill** · **stable** · **v2.0.1** · updated 2026-11-05

## Purpose

Write concise, authentic answers to job application, screening, and interview questions. The skill uses career evidence and the job description to select relevant details, then returns a copy-ready answer in chat.

## Workflow

1. **Provide the question and constraints.** Share the exact prompt, job description, desired language, and any word or character limit. In a Setup Career Stack workspace, the skill reads the career context and the archived `job.md` for that application.
2. **Ground the response.** The skill selects supported experience that answers each part of the prompt. It preserves the candidate's actual contribution and leaves unsupported claims out.
3. **Draft and fit the limit.** The answer starts with the point, uses a relevant example where useful, and stays short and natural. When a limit is supplied, the final answer includes a checked word or character count.
4. **Apply feedback.** Reusable feedback updates the shared `references/professional-voice-profile.md` in your career workspace. Both this skill and Draft Cover Letter read that profile; answer-specific preferences stay under its application-answer section.

The skill does not submit answers or fill out an application. If important evidence is missing, it asks a focused question or leaves that claim out.
