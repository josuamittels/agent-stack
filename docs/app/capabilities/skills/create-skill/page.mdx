# Create Skill

> **Skill** · **experimental** · **v0.14.0** · updated 2026-10-30

## Purpose

Use Create Skill to create a reusable skill or discipline, or to improve an identified capability with an approved change.

## Workflow

1. **Define the capability.** Settle its outcome, type, name, activation, inputs, boundaries, handoffs, resources, and observable completion conditions.
2. **Compare and design.** Inspect relevant existing skills and source material, then use [Think Deeper](/capabilities/disciplines/think-deeper) to shape the reusable workflow. Use [Pre-Mortem](/capabilities/disciplines/pre-mortem) to find concrete gaps before writing.
3. **Approve a revision.** For an existing skill, review the evidence, proposed behavior, affected files, and verification plan before implementation. A user’s approval of that proposal authorizes the scoped edits.
4. **Write and connect the capability.** Use the stack’s [skill template](https://github.com/josuamittels/agent-stack/blob/main/skills/create-skill/templates/SKILL.md), author the instructions and needed resources, and link the capability to its real callers and references.
5. **Complete the handoff.** Summarize the resulting workflow, relationships, checks, and gaps for the owning task. Stack discovery changes are coordinated by the release workflow.

For a revision to an existing skill or discipline, supply one specific source to focus the adjustment on that material. The workflow reads it directly and skips Browse Skills and broader source discovery unless you request broader research. If the source is inaccessible or leaves an essential gap, it reports the limit.

## Inputs

For a new capability, require the intended outcome, its type (`skill` or `discipline`), and a precise name.

## Result

For a discipline, return the completed-work mirror, local verification results, and remaining gaps without an evaluation package. For a skill, return the completed-work mirror and either the applicable objective package with its measurable checks or the reason no objective package was created. Do not report a verdict on the authoring output. Explain how the workflow operates and connects to skills, disciplines, and guidelines. Link the local research record while it is retained. For an unapproved proposed edit, return the concrete proposal and approval question instead of a completion claim.

## Routing and related capabilities

The [Skill Issue router](/capabilities/router/skill-issue) selects this skill when its scope matches your task.
