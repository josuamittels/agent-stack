# Translate

> **Skill** · **experimental** · **v0.5.0** · updated 2026-10-28

## Purpose

Use Translate to translate supplied text or adapt it for a target language, locale, or audience while preserving its intent.

## Workflow

1. **Confirm the target.** Identify the source text, target language and locale, audience, purpose, and any terminology or formatting constraints.
2. **Apply the language references.** Use the relevant language guide and [Natural Writing](/capabilities/disciplines/natural-writing) to preserve meaning while making the result natural for its readers.
3. **Translate and review.** Translate the complete supplied content, preserve protected names, data, structure, and claims, then check language, locale, consistency, and omissions.
4. **Return the adapted text.** Provide the translation in the requested format and flag any ambiguity that materially limits fidelity.

## Inputs

Apply this sequence before the clarification instructions below.

## Result

When used as a helper inside another requested skill, return the completed translation to that owner.
