# Draft Cover Letter

> **Skill** · **stable** · **v1.4.0** · updated 2026-11-05

## Purpose

Draft or revise a role-specific cover or motivation letter using a career profile, position details, and the [professional voice profile](https://github.com/josuamittels/agent-stack/blob/main/src/skills/draft-cover-letter/references/professional-voice-profile.md). Return copy-ready text in chat or create a PDF with the bundled layout and font.

## Workflow

1. **Provide role context.** Share the role and employer, job description, and any relevant company information. In a Setup Career Stack workspace, the supplied job description is saved as `job.md` in the numbered application folder. The skill reads `references/career-context.md`; otherwise supply a usable career profile or identify the Application System as the source when available.
2. **Ground the evidence.** The skill selects a small number of role needs and maps them to supported career facts. It keeps employer information separate from personal motivation and leaves unsupported claims out.
3. **Draft the letter.** The default sequence is greeting, short role-and-employer opening, high-level fit, one relevant experience, motivation, call to action, and sign-off. The user can request another structure or set a length limit.
4. **Choose the result.** Get the complete letter in chat by default, or request a PDF. For PDF output, the skill preserves approved wording and uses the packaged A4 layout and EB Garamond font.
5. **Give feedback.** The skill revises the full letter and saves scoped voice guidance to `references/professional-voice-profile.md` in a career workspace. That personalized profile takes priority over the bundled profile in later letters.

## Inputs and limits

Provide the job description and a career profile with relevant experience and motivation. The skill does not invent experience, results, credentials, referrals, product use, relationships, or reasons for applying. It does not submit an application or contact an employer. PDF output requires Python and ReportLab; the font license is bundled with the font.
