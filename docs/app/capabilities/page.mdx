# Capabilities

Capabilities are reusable workflows and methods for completing tasks with Agent Stack. Skills produce a defined result; disciplines provide methods that can support different tasks; the router selects the best available capability for a request.

<Cards>
  <Cards.Card title="Compose Voice Profile" href="/capabilities/skills/compose-voice-profile">Create a voice guide from brand direction, writing samples, and audience evidence.</Cards.Card>

  <Cards.Card title="Create Guidelines" href="/capabilities/skills/create-guidelines">Create or revise a reusable standard for a subject area.</Cards.Card>

## Routing

Use [Skill Issue](/capabilities/router/skill-issue) at the start of a task or when its intended outcome changes. It selects an available skill or discipline from the request and repository context. The repository's [agent instructions](https://github.com/josuamittels/agent-stack/blob/main/AGENTS.md) point to this router; if the host has no native invocation, read the selected local instructions in context.
