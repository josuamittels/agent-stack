# Changelog Standard

> **Reference** · **experimental** · **v0.1.0** · updated 2026-10-28

## Overview

Standard for creating and maintaining clear, consistent project changelogs and release notes. Use this guide when adding, reviewing, or preparing changelog entries.

## How to use this guide

Use this standard when a project needs a durable record of notable changes. A changelog helps users and maintainers understand what changed between versions and what they may need to do. It is a curated summary for people, not a copy of the commit history.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.

## Consumers

The [ship](/capabilities/skills/ship) and [update-changelog](/capabilities/disciplines/update-changelog) loads this guidance as a reference for its subject; the guide itself does not select or route a task.
