# Versioning Best Practices

> **Reference** · **experimental** · **v0.1.0** · updated 2026-10-28

## Overview

Versioning conventions for technical projects and standalone files. Use this guide when choosing initial versions, classifying changes, assigning lifecycle status, or preparing releases.

## How to use this guide

Use MAJOR.MINOR.PATCH for released projects and independently maintained files. The number communicates compatibility. Record lifecycle status separately. The rules below apply SemVer to software and establish house conventions for documents and other files.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.

## Topics

- Choose what receives a version
- Start and increment
- Record lifecycle status
- Identify and release revisions
