# Git Best Practices

> **Reference** · **experimental** · **v0.1.0** · updated 2026-10-28

## Overview

Reference for grouping file changes, ordering commits, writing commit messages, and using Git branches, worktrees, reviews, integration, and recovery. Use this guide when preparing or reviewing repository changes.

## How to use this guide

Keep repository changes focused, reviewable, and recoverable. These conventions serve contributors and agents working in existing repositories. Follow explicit task instructions, repository policy, and host requirements first. The defaults below apply where those leave a choice.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.
