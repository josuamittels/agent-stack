# Mermaid Best Practices

> **Reference** · **experimental** · **v0.2.0** · updated 2026-10-28

## Overview

House standard for Mermaid resource maps and process flows: semantic shapes, shared styling, portable configuration, direct routing, and validation.

## How to use this guide

Create diagrams whose shapes explain each resource's role, whose groups explain its place, and whose connections are easy to trace. Use this standard for new diagrams and revisions. Follow explicit user requirements when they change the appearance, grouping, or scope.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.

## Topics

- Purpose and diagram selection
- Configuration
- Shapes and colors
- Grouping and relationships
- Layout and labels
- Shared styles and syntax
- Complete examples
- Validation and delivery
