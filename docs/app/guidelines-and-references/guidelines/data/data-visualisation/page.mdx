# Data Visualisation

> **Reference** · **experimental** · **v0.2.0** · updated 2026-11-14

## Overview

Use this guide to select data and visual representations around a real question, interpretation, or decision. It covers foundations through advanced analytical displays, with defaults, alternatives, prerequisites, tradeoffs, and common misreadings.

## How to use this guide

Start with the reader's purpose and the data contract: observation unit, population, grain, measure, denominator, time, coverage, and uncertainty. Decide what to include, aggregate, filter, or leave out before selecting a chart. Use the task-to-chart table to compare plausible forms.

Consult the relevant relationship sections for amounts, ranks, deviations, composition, overlapping sets, distributions, time, cohorts, associations, models, uncertainty, geography, hierarchies, networks, and flows. For more complex work, use the multivariate, dense-data, text, scientific-field, dashboard, and interaction sections.

The encoding guidance explains position, length, area, volume, colour, shape, orientation, texture, connection, and motion. It distinguishes data dimensions from visual dimensions and explains when two-dimensional, radial, or three-dimensional forms serve the task. Use the colour-system section to separate categorical identity, magnitude, deviation, selection, status, and missingness.

Finish with accessible equivalents, medium-specific delivery, reproducible production, and evaluation. Six worked cases show how purpose changes the evidence and representation; a reusable design brief records the decisions for handoff. Analytical work still establishes data validity, statistical methods, and permissible inference.
