# Technical Documentation

> **Reference** · **experimental** · **v0.1.0** · updated 2026-10-28

## Overview

Standards for structuring, writing, verifying, and maintaining technical documentation for applications and software projects. Use this guide when assessing a repository, selecting documentation components, or creating and improving project docs.

## How to use this guide

Good documentation helps a particular reader learn, complete a task, look up a dependable fact, or understand a system. Organize it around those needs. A repository's directory tree is evidence about the software, but it is rarely a useful outline for the entire documentation set.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.
