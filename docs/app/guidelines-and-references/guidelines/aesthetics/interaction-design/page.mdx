# Interaction Design

> **Reference** · **experimental** · **v0.3.0** · updated 2026-11-11

## Overview

Reference for UX/UI interaction decisions: task models, controls, input, focus, navigation, forms, feedback, asynchronous state, recovery, adaptation, specifications, and evaluation.

## How to use this guide

Interaction design defines what people can do, how they discover and perform an action, how the system responds, and how they continue or recover. Its unit is a complete exchange between a person and a product. A button's appearance is only one part of that exchange.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.

For chart, map, and diagram decisions, consult [Infographics](/guidelines-and-references/guidelines/aesthetics/infographics) for encoding, scales, and truthful abstraction. This guide retains its own domain authority.
