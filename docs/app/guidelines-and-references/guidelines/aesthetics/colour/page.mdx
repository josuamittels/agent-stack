# Colour

> **Reference** · **experimental** · **v0.2.0** · updated 2026-10-28

## Overview

Colour reference for perception, history and language, descriptive vocabulary, theory, models and formats, conversion, composition, palettes, meaning and psychology, accessibility, interface systems, visualisation, and colour-managed production.

## How to use this guide

Colour is a perceptual experience produced by light, an observer, and a viewing context. A useful colour decision connects that experience to a purpose. It makes an action recognisable, separates information, establishes an atmosphere, or preserves an identity across materials.

Use the topics below when you create or review work in this area. Follow your repository’s conventions where they are more specific.
