# Skill Issue

Choose the smallest sufficient installed capability for the user’s outcome. Honor explicit choices and keep the selected workflow in charge of handoffs. Apply required base layers alongside the primary skill, including disciplines whose descriptions apply within other workflows. Guidelines are references, never route destinations.

## Catalog

- **answer-interview**: Draft concise, evidence-backed answers to job application and interview questions from career context and a target job description, respecting exact word or character limits.
- **ask-user-question**: Prepare, deliver, and interpret any task question for the user, including direct permission gates. Use Think Harder first only when context, evidence, or a reasonable default might resolve the gap.
- **check-colour-contrast**: Calculate the WCAG contrast ratio for two opaque hex, RGB, or HSL colors and interpret the result.
- **compose-career-profile**: Build a detailed, evidence-grounded career profile from a person's documents and staged interview answers. Use as reusable context for applications and career materials.
- **compose-voice-profile**: Compose a detailed, evidence-backed brand or author voice profile from user direction, research, guides, writing samples, visual references, and market context. Use when the user wants a reusable voice profile or tone-of-voice guide.
- **convert-colour**: Convert a color value between hex, RGB, HSL, HSV, CMYK, Lab, LCH, and Display P3 with the standalone script.
- **create-cv**: Create evidence-backed, role-tailored CV content and a PDF in a defined EB Garamond layout from a professional career profile and target.
- **draft-cover-letter**: Draft or revise a role-specific cover letter from a career profile and job details, in chat or as a designed PDF.
- **research**: Produce source-grounded research reports and literature reviews through repeatable stages, journal-filtered discovery, academic writing, deterministic citations, and Markdown, LaTeX, PDF or Word export.
- **research-literature**: Search journal-filtered scholarly databases, cross-reference work identities and citation links, and return source-linked records, abstracts, and a caller-ready search receipt.
- **setup-agent-stack**: Configure global Codex or Claude Code instructions to route tasks through installed Agent Stack skills. Use after installation to enable automatic routing or refresh its existing setup.
- **setup-career-stack**: Initialize a project workspace for managing job applications, career context, reusable CVs, and application materials. Use when setting up a fresh career application system or organizing a new job-search project.
- **spawn-evals**: Prepare and run deterministic, objective checks for completed skill outputs without qualitative assessment or agent delegation.
- **think-deeper**: Deepen a substantive, well-scoped task with professional methods, primary inputs, suitable tools, and an independent check without enlarging its goal.
- **think-harder**: Resolve missing information and ambiguity from task context, relevant caller guidelines, evidence, and reasonable defaults.
- **translate**: Translate and localize human-facing text into a target language with fluent, culturally appropriate phrasing. Use for prose, product copy, documentation, and messages that should read naturally in their destination language while preserving the source's meaning, intent, and factual claims.
- **write**: Write, edit, and translate any prose people will read, including product interfaces, websites, documentation, articles, and messages. Apply when producing human-facing text, including within implementation tasks, to preserve meaning, fit the intended voice and audience, and remove formulaic AI phrasing.

## Handoff

This catalog is not proof of installation. Check the host’s installed skill catalog and read the selected installed entry before handing off. If unavailable, report the missing capability or handle the request directly; do not install, fetch, or fabricate an invocation. Do not discover skills from private dependency snapshots, templates, or research sources. Do not change project instructions.
