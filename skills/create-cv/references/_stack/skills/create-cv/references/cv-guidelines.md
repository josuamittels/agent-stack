# CV Guidelines

## Purpose

The CV is an evidence document matched to the role's selection criteria. Select evidence and wording for this target while preserving the candidate's verified career record.

## Bullet model

Use the shortest structure that preserves meaning:

`Action + object/problem + method/scope + result`

Not every bullet needs all four elements. A concrete shipped artifact can be the result. Add context only when it changes how the achievement is understood.

## Bullet quality order

1. Measured outcome with defensible contribution.
2. Implemented operational or product change with clear scope.
3. Built artifact with scale or technical specificity.
4. Responsibility that shows ownership or complexity.
5. Generic activity — usually cut.

## Consulting-oriented standard

Strong consulting bullets make the problem, analysis, stakeholder set, and decision/output visible. Prefer:

`Diagnosed [problem] using [analysis], aligned [stakeholders], and delivered [decision/change/result].`

Avoid packing an entire project into one line. Use one problem-solving bullet and one implementation/result bullet when the project is central.

## Numbers

- Use numbers that show scale, speed, complexity, or outcome.
- Keep source qualifiers (`~`, `100+`, `up to`, `within the first month`).
- Never add percentages inferred from raw counts.
- Do not repeat the same number in multiple bullets.
- If impact is forecast, write `designed to save`, not `saved`.

## Grammar and form

- Current roles: present participle only when genuinely ongoing; otherwise simple past for completed projects.
- Past roles: simple past.
- Start with a concrete verb; avoid noun phrases.
- No first person, pronouns, periods are optional but must be consistent.
- Target 18-28 words; maximum two rendered lines.
- Keep one principal action per bullet.
- Use British English by default for English output; follow the requested language and locale otherwise.

## Seniority and ownership

Choose the exact verb:

- `led`: accountable for direction and coordination;
- `managed`: formal ongoing responsibility for people/work;
- `coordinated`: organized contributors without overstating authority;
- `built/designed`: personally produced the artifact/system;
- `contributed`: meaningful input without primary ownership;
- `supported`: assisted execution.

## Section order

Use the defined section order: name/contact, education, professional experience, personal experience, hard skills, personal interests, and language proficiency. Omit empty sections. Do not add an opening profile.

## Entry order

Use reverse chronological order within every dated section: ongoing entries first, then completed entries by most recent end date; break ties by latest start date. This is mandatory for professional experience, personal experience, and education. Use bullet selection and density—not reordered entries—to foreground role relevance.

## Evidence selection and length

- Include a supporting professional experience when it adds credible, distinct proof.
- Use no more than four bullets in any professional or personal entry.
- Let the evidence determine the total bullet count and page length.
- Include personal/freelance projects only when they add missing proof.
- Cut mission descriptions before cutting distinctive achievements.
- Use as many pages as the relevant, non-redundant evidence requires. Do not cut a stronger CV down to one page unless the applicant explicitly asks for that limit, and do not add filler to increase length.
