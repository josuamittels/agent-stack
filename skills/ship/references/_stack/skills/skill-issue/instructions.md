# Skill Issue

Choose the smallest sufficient installed capability for the user’s outcome. Honor explicit choices and keep the selected workflow in charge of handoffs. Apply required base layers alongside the primary skill, including disciplines whose descriptions apply within other workflows. Guidelines are references, never route destinations.

## Catalog

- **answer-interview** (stable): Draft concise, evidence-backed answers to job application and interview questions from career context and a target job description, respecting exact word or character limits.
- **ask-user-question** (stable): Prepare, deliver, and interpret any task question for the user, including direct permission gates. Use Think Harder first only when context, evidence, or a reasonable default might resolve the gap.
- **audit-accessibility** (experimental): Audit a supplied interface, design, infographic, document, or media artifact against applicable accessibility standards. Fill a modular report.md with evidenced criterion outcomes, transparent scores, and prioritized remediation and verification actions.
- **audit-design** (experimental): Coordinate a design audit through Audit UX and its accessibility sub-audit, then add a deep aesthetic critique of intent, composition, coherence, craft, expression, and restraint. Return linked reports and one prioritized improvement plan for the supplied design.
- **audit-ux** (experimental): Audit how well a supplied design, interface, or information artifact serves its users' jobs, needs, expectations, and tasks. Clarify unresolved customer context, include an accessibility sub-audit, and fill a modular UX report with evidence, prioritized improvements, and validation actions.
- **browse-skills** (experimental): Find and inspect related public skills for inspiration through GetEdge and original source repositories. Use when in need of comparable methods, skills, agent orchestration, conventions, or failure-handling approaches.
- **check-colour-contrast** (stable): Calculate the WCAG contrast ratio for two opaque hex, RGB, or HSL colors and interpret the result.
- **compose-career-profile** (stable): Build a detailed, evidence-grounded career profile from a person's documents and staged interview answers. Use as reusable context for applications and career materials.
- **compose-voice-profile** (stable): Compose a detailed, evidence-backed brand or author voice profile from user direction, research, guides, writing samples, visual references, and market context. Use when the user wants a reusable voice profile or tone-of-voice guide.
- **convert-colour** (stable): Convert a color value between hex, RGB, HSL, HSV, CMYK, Lab, LCH, and Display P3 with the standalone script.
- **create-cv** (stable): Create evidence-backed, role-tailored CV content and a PDF in a defined EB Garamond layout from a professional career profile and target.
- **create-docs** (experimental): Create evidence-grounded documentation in root/docs for people who use a repository's product or resources. Explain its structure, components, and supported use; do not default to contributor or maintainer manuals.
- **create-guidelines** (experimental): Create or revise reusable guideline documents. Use to define domain standards, conventions, tool usage, or best practices, or to repair a guideline defect found while evaluating a skill.
- **create-skill** (experimental): Create new skills and disciplines, or propose and implement approved improvements to existing ones in the agent stack. Prepare objective checks only when a skill has meaningful script-verifiable criteria.
- **draft-cover-letter** (stable): Draft or revise a role-specific cover letter from a career profile and job details, in chat or as a designed PDF.
- **mind-wandering** (experimental): Open creative possibilities through playful association, reframing, changes of representation, and deliberate return. Use to explore unfamiliar directions, escape fixation, or develop an unusual idea while preserving the task's intent.
- **pre-mortem** (experimental): Find concrete failure paths in an adjustable, consequential plan before commitment by imagining it has failed and working backward.
- **quit-the-yap** (experimental): Write concise, direct in-chat answers in English Absolute style while preserving the details needed for meaning and action.
- **research** (stable): Produce source-grounded research reports and literature reviews through repeatable stages, journal-filtered discovery, academic writing, deterministic citations, and Markdown, LaTeX, PDF or Word export.
- **research-literature** (stable): Search journal-filtered scholarly databases, cross-reference work identities and citation links, and return source-linked records, abstracts, and a caller-ready search receipt.
- **setup-agent-stack** (stable): Configure global Codex or Claude Code instructions to route tasks through installed Agent Stack skills. Use after installation to enable automatic routing or refresh its existing setup.
- **setup-career-stack** (stable): Initialize a project workspace for managing job applications, career context, reusable CVs, and application materials. Use when setting up a fresh career application system or organizing a new job-search project.
- **ship** (experimental): Ship a reviewed change by following the target repository's release, changelog, test, and Git workflow. Use when asked to ship, release, push, or create or update a pull request.
- **show-me-your-work** (experimental): Keep an evidence-linked decision log for long-running, multi-phase, or unattended work, then audit it before handoff.
- **spawn-evals** (stable): Prepare and run deterministic, objective checks for completed skill outputs without qualitative assessment or agent delegation.
- **think-deeper** (stable): Deepen a substantive, well-scoped task with professional methods, primary inputs, suitable tools, and an independent check without enlarging its goal.
- **think-harder** (stable): Resolve missing information and ambiguity from task context, relevant caller guidelines, evidence, and reasonable defaults.
- **translate** (stable): Translate and localize human-facing text into a target language with fluent, culturally appropriate phrasing. Use for prose, product copy, documentation, and messages that should read naturally in their destination language while preserving the source's meaning, intent, and factual claims.
- **update-changelog** (experimental): Create, update, or prepare a repository changelog from verified changes. Use when the user asks to record changes, maintain CHANGELOG.md, or prepare a changelog release section.
- **write** (stable): Write, edit, and translate any prose people will read, including product interfaces, websites, documentation, articles, and messages. Apply when producing human-facing text, including within implementation tasks, to preserve meaning, fit the intended voice and audience, and remove formulaic AI phrasing.

## Handoff

This catalog is not proof of installation. Check the host’s installed skill catalog and read the selected installed entry before handing off. If unavailable, report the missing capability or handle the request directly; do not install, fetch, or fabricate an invocation. Do not discover skills from private dependency snapshots, templates, or research sources. Do not change project instructions.
