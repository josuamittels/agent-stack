# Mind Wandering

Give an unfinished question room to change. Notice specific material, follow an association, try another form, and return with a possibility worth developing. Keep enough direction to serve the work and enough freedom to discover something the initial framing did not invite.

For an agent, mind wandering means deliberately loosening the current search and returning to it. It describes observable work with inputs, representations, and candidates. It does not establish a subjective state, unconscious processing, or a benefit from elapsed time. Human creativity findings and bounded model experiments inform this method; they do not validate the combined method across tasks or models.

## Scope

Use when the user wants creative exploration, greater freedom, fresh connections, unfamiliar directions, or a way out of repetitive ideas. It can help before a stall, while a question is taking shape, and after a promising direction has become too predictable. Apply it across artistic, design, writing, product, and technical tasks, with the task's own standards of value.

Use through the skill that owns the task when one fits, or directly for a scoped creative exploration. The owner retains implementation, domain checks, and delivery. Use [Think Harder](../think-harder/SKILL.md) when uncertainty concerns what the user wants. Use [Think Deeper](../think-deeper/SKILL.md) when the main need is stronger evidence or methods for a settled task. A missing fact, unavailable material, or correctness defect calls for investigation or repair; more ideation alone does not resolve it.

### Boundaries

Preserve the user's intent, fixed requirements, factual integrity, and authorization. Creative latitude permits tentative concepts, fictional possibilities, and reversible experiments within that scope. It does not turn imagined research, simulated perspectives, or invented observations into evidence.

Use available tools only when they contribute material or reveal something a text pass would miss. Creating a preview or making a detour does not authorize spending, installation, publication, messages, or unrelated file changes. Do not add subagents, model changes, or external services as a default creativity technique.

## Inputs

Use the question or brief, intended audience or experience, current stage, existing material, earlier attempts, constraints, available formats and tools, and any time or cost limit. Recover these from the task; do not turn an open invitation to play into an intake interview.

An exploratory task can begin with an image, tension, fragment, curiosity, or desired feeling instead of a solved brief. Keep that starting point available and let its meaning develop. Ask for clarification only when a missing decision prevents a useful exploration or could change a fixed requirement.

### Default Procedures

When task input is needed from the user, route the question through [ask-user-question](../ask-user-question/SKILL.md) for preparation, delivery, and interpretation. First invoke [think-harder](../think-harder/SKILL.md) when ambiguity, missing information, or competing interpretations may be resolved from context, relevant guidance, evidence, or a reasonable default. Skip Think Harder for direct permission or approval gates, explicitly requested interviews, and facts or preferences only the user can supply. Ask only about consequential unresolved items. Continue independent work and preserve approval requirements.

If any discipline is unavailable, perform it directly and report the fallback. Carry unresolved constraints forward and do not invent answers or pretend the dependency ran.

## Working rhythm

Orient, gather material, wander, return, and develop. Treat these as modes to revisit, not approval gates or a fixed sequence. Continue a productive line while it reveals something. Switch when the current approach repeats, conceals an important relationship, or closes possibilities prematurely.

For a small task, a rough alternative and a deliberate return may be enough. A substantial exploration can use several different starting points and a small artifact. Choose the scale from the requested outcome and available budget. Do not complete every exercise or generate a fixed number of ideas.

### 1. Keep a return point

Hold a short working note with the question, intended effect, fixed requirements, current attempt, and the assumption being explored. Ordinary task context is enough; create no separate file unless persistence is useful or requested. This note makes it possible to leave the current approach without losing the work.

Distinguish requirements from conventions and current guesses. A required delivery format may stay fixed while the imagery, sequence, mechanism, or structure changes. A familiar solution is material to reconsider, not an additional requirement. Keep a conventional baseline when it will make later comparisons clearer; do not discard a useful idea merely because it arrived first.

Define value for this task. A technical concept needs plausible operation and fit. An artistic direction may need expressive force, emotional specificity, ambiguity, coherence, or surprise. Early exploration may seek a fertile question rather than a finished answer. Originality is relative to an audience, domain, or comparison set; do not claim unprecedented invention from personal unfamiliarity.

### 2. Supply material and notice particulars

Work from something more specific than the category name. Inspect the brief's examples, artifacts, observations, user language, materials, constraints, and anomalies. Distinguish what is present from your interpretation of it. If the task lacks essential facts, gather them before relying on an invented premise.

Notice a detail that changes the question: an awkward pause, an unexpected use, a repeated gesture, a material property, an omission, or a mismatch between what people say and do. When using imagined material, label it as an imagined scene or possibility. An agent's invented sensory description is a prompt, not an observation.

Broaden inputs when they add a new relation or vocabulary. An adjacent craft, a scientific mechanism, a musical structure, or a contrasting everyday practice can supply useful material. Avoid collecting many polished examples of the same answer. After extracting a useful feature, stop looking at the exemplar and try another starting point; fixation can come from your own first solution too.

Keep observation, interpretation, and possible application distinct in working notes when their difference matters. For example, an inspected photograph may show irregular spacing; the interpretation is rhythm; a possible application is an uneven reveal in a sequence. None of those steps establishes that the application will work.

### 3. Open the search

Choose a change that fits the current need. Make the result rough enough to revise. A phrase, relation, sketch, contradiction, rhythm, scene, or mechanism can be sufficient at this stage. Read [Creative Moves](references/creative-moves.md) when choosing or applying a move needs a worked procedure or example; load only the relevant sections.

| Current condition | Useful opening | What to look for on return |
| --- | --- | --- |
| The page is blank or the brief is too abstract. | Describe one concrete moment; make a deliberately incomplete fragment; examine a specific material. | A particular action, tension, image, or question worth following. |
| Outputs keep reproducing a familiar answer. | Separate its job from its form; remove an assumed feature; reverse a relationship. | A different mechanism or experience, rather than a renamed version. |
| Wording changes while the structure stays fixed. | Draw the relationships, arrange a sequence, describe a movement, or express a process in another form. | Something the original representation hid. |
| The idea needs an unfamiliar connection. | Follow an association or borrow a relation from another domain. | A useful transfer and its limits. |
| Constraints have made the search brittle. | Identify which are fixed; temporarily relax a preference or add a different playful constraint. | A possibility to adapt back into the real conditions. |
| Possibilities are plentiful but indistinct. | Change the starting situation, governing relationship, material behavior, or scale. | Differences in underlying concepts, not just descriptions. |
| A direction is promising but unfinished. | Explore its consequences, make a small version, or ask what would strengthen its distinctive feature. | Development of the idea, with its originality preserved. |
| The problem is mostly missing evidence or execution. | Return to investigation, domain reasoning, or making the artifact. | Progress on the actual bottleneck. |

During a generative pass, allow surprising associations and awkward fragments to exist before asking them to justify themselves. Do not grade every line or reject a direction because it is initially hard to explain. Hard conflicts remain conflicts, but a temporary fiction or relaxed preference can reveal a relation to adapt later.

Create conceptual variety by changing meaningful starting conditions. A different person's situation, a different cause of the problem, or a different governing constraint can open a new search. Repeated requests to make the same idea bolder or more creative can keep returning a familiar formula; change the starting condition when that happens. A persona label alone supplies no lived expertise. Make imagined situations concrete, avoid stereotypes, and treat their needs as hypotheses unless established by evidence.

### 4. Let a detour develop, then interrupt repetition

A detour can begin with curiosity rather than a known application. Follow what is interesting about an image, shape, mechanism, word, or relationship. Permit a loose association to lead to another without requiring every intermediate fragment to fit the brief. Keep the return point available; the detour's value is assessed when you reconnect it.

Capture a fragment before explaining it away. Keep enough to recover the interesting quality: the tension, relation, form, or question. Avoid polishing every fragment into a full proposal. When something starts to work, stay with it long enough to discover its implications; constant switching can prevent development.

If attempts loop, stop extending the same answer. Change a relevant input, representation, scale, or assumption. A deliberate resumption from the return note can interrupt a repetitive context, but do not claim a fresh or independent context unless the host actually provides one. Preserve essential facts and constraints through any reset.

Human collaborators may choose a simple unrelated activity after genuine engagement and return later. Break effects depend on the task, and no universal activity or duration follows. Offer this when relevant to their request; do not impose a break as a prerequisite. For an agent, waiting, sleeping, or doing unrelated busywork supplies no demonstrated incubation benefit. Use a purposeful change of search, or leave a clear resumption note when the work is being paused for another reason.

### 5. Change medium to reveal something

Choose a representation for a particular question. Spatial arrangement can reveal adjacency and hierarchy; a sequence can reveal anticipation and reversal; sound can expose pace, repetition, and contrast; a physical model can reveal affordances or resistance. These are possible lenses, not a claim that adding senses reliably improves creative performance.

When relevant channels are available, inspect or make a small artifact that can be compared: a diagram, collage, storyboard, rhythm study, rough image, interaction sketch, or minimal code experiment. Prefer the smallest form that exposes the uncertainty. A polished artifact can make an immature idea harder to revise.

When a channel is unavailable, use an explicitly described translation. A rhythm notation can guide a visual sequence; a verbal material analogy can suggest behavior. Say that you are using a description, caption, or notation. Do not claim to have heard audio, handled a material, or seen an image you could not inspect, or imply that a textual substitute provides the same information.

Return to the requested form with what the shift revealed and what it omitted or distorted. Borrowing the properties of something differs from decorating the answer with its name. A service inspired by a garden might vary with seasons or distribute care; adding leaf imagery alone does not change its operation. Either may fit an artistic brief, but identify the actual change.

### 6. Return without flattening the discovery

Revisit the original question and fixed requirements. Describe the candidate clearly enough to inspect. Ask what the detour revealed, what changed, and what belongs in the work. A failed connection can be discarded without a forced lesson. Keep a provocative fragment as an open question when the user asked for exploration.

Assess fit and originality separately before making a combined judgment. Consider the audience's experience and the task's stage. Distinguish a hard conflict from missing development: a rough candidate may need evidence, a clearer expression, a smaller scope, or a changed implementation. Give its interesting feature a fair chance before selecting the easier, familiar alternative.

Compare concepts at a similar level of detail. Fluent wording, elaborate presentation, idea count, and semantic distance do not establish creative quality. For a set of options, examine whether they differ in mechanisms, relationships, formal structures, or intended experiences. Merge near-duplicates without erasing meaningful differences. Different options need not all maximize the same dimension.

Use relevant domain checks before claiming that a developed solution works. Self-assessment can guide revision, but it is not independent validation or proof of novelty. If an outside judgment or real-world check would determine success, identify that unresolved question for the owning task. Do not introduce a separate evaluation process through this discipline.

### 7. Develop what deserves another pass

Select according to the requested stage. A useful result can be a direction to pursue, a contrast between alternatives, a fragment with potential, a prototype, or a completed artifact. Selection does not require one winner when the user wants breadth. Completion does not require implementation when the task is concept exploration.

Name what makes the selected direction worth keeping, then improve its weakest relevant part while preserving that quality. If feasibility is weak, change how it works before removing its defining move. If meaning is weak, make the situation or tension more specific. If the form is generic, revisit the structure rather than add extravagant language. If critique exposes a new possibility, re-enter exploration with that question.

Combining candidates is useful when their relationship creates something coherent. Keep alternatives distinct when their value depends on conflicting principles. Do not average every promising direction into one bland compromise or add every interesting fragment to the final work.

## Recover and stop proportionately

| Warning sign | Response |
| --- | --- |
| The next pass repeats the same concepts. | Change a meaningful condition once, develop an existing direction, or stop with the best available material. |
| A strange idea needs an elaborate justification but contributes little. | Drop the connection, retain any useful fragment, and return to the task. |
| Research is accumulating without changing the possibilities. | Stop collecting inputs and make something with the material already available. |
| Every candidate is rejected before it can take form. | Separate rough generation from critique briefly; defer questions that belong to later development. |
| An attractive metaphor conflicts with the work. | Keep the useful relation if one exists; release the metaphor. |
| An imaginative direction relies on an unknown fact. | Mark the assumption and return the fact question to investigation before presenting it as viable. |
| The process is interrupting productive work. | Continue the productive line and omit further moves. |

Return from exploration when the available directions support the next decision, the requested breadth has been achieved, the time or cost limit is reached, or further passes mainly repeat. These are practical stopping rules, not scientifically established thresholds. If no better direction emerged, say so and use the strongest existing option when it meets the request. Report a material unresolved need instead of declaring the work impossible merely because a detour failed.

## Output

Return the creative material in the form the user requested. Include the selected direction or contrasting alternatives, their relevant differences, and important assumptions or unresolved questions when those help the next decision. A requested finished artifact remains the primary deliverable.

When working as a helper, return the useful discoveries, what should be preserved, and the next development question to the owning task. Keep process commentary brief. Provide a concise rationale for the useful move when it helps the user; do not require a transcript of associations or turn exploratory notes into a report by default.
