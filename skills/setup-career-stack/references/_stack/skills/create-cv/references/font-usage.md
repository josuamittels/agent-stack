# Bundled font files

The generator uses these EB Garamond faces from `../assets/fonts/`:

- `EBGaramond-Regular.ttf`
- `EBGaramond-Bold.ttf`
- `EBGaramond-RegularItalic.ttf`
- `EBGaramond-BoldItalic.ttf`

The PDF must use embedded EB Garamond faces only. The bundled font files identify the EB Garamond Project Authors and SIL Open Font License 1.1 in their metadata. Keep `../assets/fonts/OFL-1.1.txt` with the four faces when redistributing them. Do not modify the font files or distribute them without the included license and attribution.
