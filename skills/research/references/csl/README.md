# APA 7 style attribution

The unmodified [apa.csl](apa.csl) is vendored from the [Citation Style Language styles repository at commit 3c6698d791a83016d699f50cbbea857f6ee3d2f8](https://github.com/citation-style-language/styles/blob/3c6698d791a83016d699f50cbbea857f6ee3d2f8/apa.csl), retrieved 2026-10-30. Its embedded metadata identifies APA Style 7th edition, authors Brenton M. Wiernik and Andrew Dunning, and its contributors. The original XML metadata and attribution remain intact.

The style is licensed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/), as stated by its embedded rights element. No modifications have been made. The license applies to the CSL style, not automatically to research prose merely formatted with it. Preserve attribution and applicable license obligations when redistributing or modifying the style. Runtime conversion uses this local file without fetching styles from the network.
